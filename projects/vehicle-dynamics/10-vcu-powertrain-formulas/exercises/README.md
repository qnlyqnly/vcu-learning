# 第10期 · 独立练习与检查点

先在 MATLAB 中执行 `results = run_all_examples(false);`，再修改 `examples/demo_parameters.m` 中的**教学参数**，观察结果如何变化。每次改动都应备份原始参数或恢复初值。入口中的断言检查计算关系，不会用固定初值阻断参数练习；`expected_results.txt`仅对应原始参数。

## 练习一：根据电压、电流计算功率

把 `p.battery.currentA` 从125改为150，`batteryMeasuredPowerKW` 应从75增加到90 kW。**请注意：仅改变测量电流不会自动改变 BMS 允许功率**。如果限扭结果仍为200.55 N·m，这是符合脚本假设的。

## 练习二：BMS放电功率限制

把 `p.battery.allowedDischargePowerKW` 从75改为65，其他不变。计算新的电机机械功率与正向扭矩上限。提示：`(65 - 5) * 0.90 = 54 kW`，`9550 * 54 / 3000 = 171.90 N·m`。

## 练习三：电机转速与最大扭矩

在1500rpm时用同一63 kW计算功率对应扭矩，得到401.1 N·m，但这**不表示电机允许输出401.1 N·m**：还需要通过电机轴端扭矩上限、MCU与其他限制仲裁。

## 练习四：整车质量与加速度

把整车质量从2500kg改为3000kg。保持其他条件相同，比较平路加速度。注意滚阻随质量变化，因此不应简单地把加速度乘以2500/3000。

## 练习五：坡度百分比与坡角

在 `uphillGradePercent = 10` 时，通过MATLAB观察 `uphillAngleDeg` 是否约为5.71°。解释为什么不能把10%直接当成10°。

## 练习六：回馈限扭

把 `p.regen.allowedChargePowerKW` 从20改为10。由于充电能力降低，回馈制动允许负扭矩幅值应降低，且负扭矩的方向约定保持不变。

## 练习七：看曲线

运行 `results = run_all_examples(true);`。查看生成的 `figures/motor_torque_speed_generated.png`，解释为什么转速在基速以下时扭矩保持上限、基速以上时扭矩随转速下降。
