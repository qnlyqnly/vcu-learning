# CAN 通道修改验证检查表

本表是待执行清单，不是测试报告。仓库 CSV 只记录虚构教学数据，不能替代模型参数的实际复读结果。

## 修改前

- [ ] 备份原模型和相关配置，另存副本，记录文件名与版本。
- [ ] 记录 MATLAB、Simulink、模块库和支持包版本。
- [ ] 明确目标模型、层级、模块类型；确认引用模型、变体和链接库处理范围。
- [ ] 统计目标模块总数及各通道数量，逐项保留完整模块路径。
- [ ] 记录原始通道与参数实际取值方式，不把显示名称当作参数。
- [ ] 记录报文 ID、DBC 文件及消息引用、模块连线和非目标参数作为基线。
- [ ] 按原始快照生成目标表：0→0、1→2、2→1，人工确认后再修改。

## 修改后

- [ ] 从模型重新读取每个目标参数，与原值和目标值逐行比较，而非只打印准备写入的值。
- [ ] 检查原 CAN0 对象全部保持不变。
- [ ] 检查原 CAN1 对象全部变成 CAN2，原 CAN2 对象全部变成 CAN1。
- [ ] 检查目标总数不变、无遗漏和重复，非目标模块未改变。
- [ ] 检查报文 ID、DBC 引用与内容、模块名称和连线均未意外变化。
- [ ] 对比差异：只应有本次批准的通道参数变化；保存并重新打开副本再核对。
- [ ] 确认设备通道映射及共享配置是否需要配套调整；不凭教学编号推断硬件接口。
