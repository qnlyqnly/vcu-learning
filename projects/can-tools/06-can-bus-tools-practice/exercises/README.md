# 第06期 · 四组练习

本页所有数值和变量名均为独立设计的虚构示例。没有设备时先做纸面练习；不要把“预期”写成“已测得”。

## 练习A：终端电阻

对照 [拓扑图](../docs/can_topology.svg) 和 [四组理论算例](../examples/termination_cases.csv)。

1. 找到两端各一个120Ω，说明为什么它们是并联。
2. 用 `1/R = 1/R1 + 1/R2 + ...` 分别计算：120∥120、单个120、三个120并联、120∥120∥1200。
3. 如果测得约60Ω，能否单凭它断言CAN通信正常？
4. 如果额外并联1.2kΩ，能否把它当成通用修复办法？

若在独立低压教学台架实际测量：先确认全部节点断电并按设备要求等待放电，核对H/L和表档，再记录。不要在带电总线上使用电阻档。

| 理论值 / 实际读数 / 表型号 | 待填写 |
| 读数差异的可能原因 | 待分析 |

参考答案：60Ω、120Ω、40Ω、约57.14Ω。两个终端都跨接同一对线，所以并联。60Ω不能排除断续接触、波特率错误、波形干扰等问题；额外电阻改变负载，不保证改善，更不能替代查明原拓扑。

## 练习B：示波器观察

对照 [差分图](../docs/can_differential.svg)，先完成无设备练习：

1. H=3.5V、L=1.5V，H−L是多少？属于显性还是隐性？
2. 500kbit/s和250kbit/s，一个理论比特各有多宽？
3. 探头本体10X、通道设置1X，应先改哪个设置？
4. 单探头先测H再测L，能得到某一瞬间的H−L吗？

有设备时，先在示波器专用补偿输出上练习，不连接车辆：
连接探头到CH1 → 核对本体与通道倍率 → 在专用补偿端按仪器说明连接 → 调整V/div和Time/div让方波清楚可见 → 选择边沿触发和CH1源 → 记录设置。补偿输出的电平与频率按设备说明，不使用CAN参考电平代替。

观察CAN前另行确认参考地、保护地与隔离方案。两通道方案通常是两地夹接同一个已确认安全的参考地，尖端分别接H/L，再做CH1−CH2；设备额定值、共模范围和连接安全必须先确认。差分探头按其说明连接。普通地夹不得直接夹H或L。

## 练习C：ZCANPRO接收与采集

无设备练习：打开 [虚构CSV](../examples/can_frames.csv)，圈出时间、通道、方向、帧类型、ID、DLC和DATA；单独计算0x610相邻记录间隔，解释CSV与ASC的区别。

设备操作只在已经确认配置的独立教学台架进行：

1. USB-CAN连接电脑，确认设备识别和驱动状态。
2. 打开ZCANPRO，选择实际设备及目标CAN通道。
3. 根据该台架配置设置波特率；不能看见500或250就随便选。确认适用的接收/监听模式及设备终端电阻开关。
4. 新建CAN视图并选择同一设备和通道，检查是否有接收数据。
5. 使用实时保存功能选择ASC路径，开始记录，再停止保存。
6. 检查文件存在且非空，用文本查看器核对时间、通道、ID、DLC和DATA。按钮位置以版本界面为准。

本练习无需主动发送。普通发送窗口是发送功能，不是接收保存窗口。离线回放应单独建立回放源，选择文件与目标视图；本期CSV不能直接回放，更不要映射到真实车辆发送。

| ASC文件名 / 非空检查 | 未执行 |

参考答案：0x610间隔为20、20、40ms。CSV是本项目自定义学习表；ASC是工具支持的日志格式，字段和文件结构不同。只看到40ms间隔不能确定是丢帧，还需协议周期、过滤规则和采集状态。

## 练习D：MeCa变量观察

无设备练习：画三列“总线数据—DBC解释—ECU内部变量”，回答：总线能看到报文，是否就一定能看到内部变量？

有匹配软件和授权教学工程时：

1. 新建MeCa项目，导入与ECU软件版本匹配的A2L。
2. 找到Measurement中的一个**实际存在**的测量变量。
3. 将它拖入数字显示控件，或在控件属性中关联对应变量，保存设计区。
4. 按教学工程配置通信设备、通道和协议参数，开始连接与同步。
5. 观察值是否更新，记录单位、刷新状态、连接状态和实际版本；不修改标定、不刷写。

`Demo_RxCount`、`Demo_Ready`仅是纸面示例名，并非承诺存在于某个A2L。若没有匹配A2L或内部测量通信支持，此项停留在理论练习，不猜地址、不拿DBC代替A2L。
