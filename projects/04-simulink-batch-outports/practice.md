# 5 路 Outport 动手练习

## 第一关：先跑通

运行 `create_outports`，打开 `outport_demo.slx`，对照 README 检查以下内容：

- [ ] 有 5 个模拟信号源（Constant）
- [ ] 有 5 个 Outport，名称分别为 Speed、Torque、Voltage、Current、Temperature
- [ ] 同名信号一一连接，没有漏接、错接
- [ ] 模块上下排列，没有明显重叠
- [ ] 运行 `check_outports` 后，5 组检查均显示 `OK`（若报错先排查）

**别把模块名称和信号线名称混为一谈：** 这里主要检查 Outport 的模块名称；如果后续需要对信号线单独命名，还要另行设置和核对。

## 第二关：自己多加一组

将 `create_outports.m` 中的名称列表增加 `'Pressure'`。为了避免同名冲突，把模型名称从 `outport_demo` 改为 `outport_demo_6`，再运行。注意检查脚本也要改成新的名称列表及模型名称。

思考：为什么不能只在一个脚本里增加名称，另一个检查脚本却完全不变？

## 第三关：理解真实问题与演示的区别

假设**已有一个子系统**，它有 5 个输出端口，名字与顺序分别对应：

| 源模块输出序号 | 应连接的 Outport 名称 |
| --- | --- |
| 1 | Speed |
| 2 | Torque |
| 3 | Voltage |
| 4 | Current |
| 5 | Temperature |

这时无需再创建 Constant。先核对现有源模块的 5 个输出序号，再考虑让脚本批量创建右侧 Outport 并连接。**不能仅凭名称相似就直接连线。** 如果接口顺序变了，按旧顺序连接会接错。

本项目的脚本只实现「独立演示模型」；它**没有**实现对现有复杂子系统的自动识别与改线，避免造成误解。

## 常见错误

**提示模型已存在**：脚本设计为不覆盖同名模型。先确认是否运行过，或者修改新模型名称。

**找不到 `create_outports`**：检查 `.m` 文件名及 MATLAB「当前文件夹（Current Folder）」。

**Outport 创建了但连线错误**：检查源模块名称、`/1` 端口编号和对应关系；不要使用空的 `try-catch` 忽略错误。

**脚本运行成功是不是功能验证完成了？** 不是。脚本只负责建模和结构检查，还需要根据功能目标进一步仿真或测试。
