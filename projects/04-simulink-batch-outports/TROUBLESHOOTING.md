# 第04期排错与常见疑问

## 脚本在哪里运行？

把本目录所有.m文件放在独立练习文件夹，将MATLAB Current Folder切到这里。命令窗口输入create_batch_demo，执行同名函数文件。不要粘贴到模块参数、回调或MATLAB Function模块中。

命令窗口用于启动和查看结果，.m文件保存整段流程供复用，不需要逐行复制50次建块语句。

## 报错先查什么？

| 现象或标识 | 可能原因 | 处理方向 |
| --- | --- | --- |
| 找不到create_batch_demo或batch_config | 文件不全、Current Folder不对 | 下载本目录全部.m，检查文件夹 |
| episode04:Exists | 同名模型已加载或文件存在 | 在配置中换新模型名 |
| episode04:Config | 名称、端口或数值配置不符 | 同时核对三个列表长度及内容 |
| episode04:PortCount | 源输出数与映射不一致 | 核对完整源输出映射 |
| episode04:ExistingOutports | 已有根输出 | 不对原模型重复调用，用新演示模型 |
| episode04:Collision | 目标名与已有模块冲突 | 停止并核对，不依赖自动加后缀 |
| episode04:Connected | 源端口已有线 | 本函数不替换已有线，检查是否重复执行 |
| episode04:MissingOutport | 目标删除/改名或配置不对应旧模型 | 恢复生成时配置并检查模型 |
| episode04:WrongSource | 来源与配置不一致 | 对照原始映射检查实际连线 |
| episode04:Order | 根Port编号变了 | 查Outport参数，不能只看名字 |
| episode04:InnerValue | 模拟值或内部Port变了 | 查源内部Constant与Outport |
| 更新模型时报错 | 库、版本或模型配置问题 | 记录完整报错及版本，不忽略错误写成功 |

## 生成以后，模型还依赖脚本吗？

脚本在编辑阶段搭模型。save_system成功后模块和连线保存在.slx。本例未把生成函数挂到模型回调，也未把cfg作为模块参数引用，Constant写入的是数字文本，打开已保存模型无需再次生成。

修改batch_config不会自动改写旧模型。检查按当前配置进行，因此改配置后应换新模型生成，检查旧模型先恢复当时配置。

## 会影响生成的C代码吗？

脚本和手工是两种建模方式。最终模型、数据类型、配置和优化等共同影响生成代码，不能只凭建模方式断言代码完全一样。

本项目没有执行代码生成或验证部署目标。生成函数没有放进MATLAB Function块，不能把它当作要部署的控制算法。结构检查不能替代对应的代码生成验证。

## 只有50个名字，就能知道接谁吗？

不能。函数只使用明确的sourcePorts映射，不按名字猜业务含义。源接口顺序变化时先重新核对映射，再建模和检查。

## 50路为什么纵向排得很长？

为了让配置行与目标行一一对应，需缩放和滚动。本例未实现复杂自动布局或接口分组，画布可读性仍需实测检查。

## 转double、处理Bus或Enabled Subsystem怎么办？

当前未实现这些场景。若加入类型转换，检查也要改为“源→转换→目标”的链路检查，不能继续要求目标直接接源。类型、范围、单位和转换影响应另行验证。

先在本例把创建、命名、映射与检查做完整，再设计复杂接口的独立练习。
