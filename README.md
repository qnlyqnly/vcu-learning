## 新手推荐顺序

1. **第01期：把表变成文件。** 学会填写通信矩阵，观察脚本如何生成 DBC。
2. **第02期：把定义和报文对应起来。** 对照 DBC 与虚构报文，练习手工解析。
3. **第03期：把信号边界分清楚。** 理解独立信号、跨字节数值和起始位，完成位运算核对。
4. **第04期：动手做 Simulink 建模。** 从 5 路入门到 50 路输出，练习批量命名、端口映射、连线检查和排错。

## 按技术方向浏览
